# Rescue Animal Dashboard Frontend

The frontend creates the user interface from which the user can interact with the data table, geo map, and chart.

## Getting Started

1. Open a terminal shell and navigate to the /frontend directory
2. Run the following command to install all necessary dependencies
```bash
npm install
```
3. Run the following command to start the web application
```bash
npm run dev
```
4. Open a web browser and navigate to the localhost port that the application is running on to view the dashboard. Ex: http://localhost:5173/
